# shinsaku-calendar

**FANZA の発売・配信予定を、日付から引くカレンダー。**

darekore.jp（`darenano`）とは**別のものを作る**。名鑑の焼き直しではない。
2026-09-12、darekore.jp が抱えた問題を1つずつ潰した設計にしてある。

- 本番URL: 未定（ドメインが決まったら `SITE_DOMAIN` 1箇所で切り替える）
- 配信: GitHub Pages

## なぜ作り直したか（darekore.jp で分かったこと）

### 1. アダルトサイトは、アダルトでないクエリでは出ない

2026-09-11 に実測した。`site:darekore.jp` をセーフサーチ別に引くと、

    Off     10ページぶん出る
    Filter  1件だけ

**順位は落ちていない**（人名クエリで 2.9〜7.7位）。それなのに表示回数が99%減った。
Google がサイトをアダルトと判定し、**出す相手を絞っている**。これは覆せない。

**だからこのサイトは、検索意図が最初からアダルトのクエリだけを狙う。**
人名で拾おうとしない。「9月に出る新作」「このレーベルの新作」を探す人に向ける。

### 2. 大量の自動生成ページは、Google が取りに来ない

darekore.jp は 59,445ページを作り、そのうち **21,147件が
「発見済み - 現在インデックス登録されていません」**になった。
重複判定はわずか3件。**似ているから弾かれたのではなく、取りに来ていない。**

**このサイトはページ数を3桁に抑える。** 月別・ジャンル別・レーベル別だけ。
作品1本につき1ページは作らない。

### 3. 成果は「リンクの単位」で決まる

darekore.jp のアフィリエイト成果は、**紹介した作品からは1件も出ていない**。
売れたのは全部「企画もの」で、名鑑からはリンクしていない商品だった。

> **出演者名鑑は「この人が誰か」を調べる場所で、「この作品を買う」と決める場所ではない。**

**発売予定を見に来る人は、買うと決めている人。** だから作品単位のリンクだけを置く。
カテゴリ報酬（10%）ではなくダイレクト報酬（35%、キャンペーン中は70%）が乗る。

### 4. 未申請のIDを使わない

参加規約 第7条は「当社に申請していないサイトにおけるアフィリエイトIDの利用行為」を
禁止行為として挙げ、罰則は「**事前に何らの通知なく**、参加登録の解除、報酬の没収」。

**承認が下りるまで、アフィリエイトIDを付けない。** 素の作品ページURLを置く。
作品名・出演者名・発売日の掲載自体には制限がない（DMM の画像利用の制限に明記）。
承認後に `FANZA_AFFILIATE_ID` を入れて取り直せば、リンクがアフィリエイトURLに変わる。

### 5. 画像は借りているもの。切り抜かない

2026-09-09、グラビア名鑑が「著作物の無断使用」でサイト審査に落ちた。
原因の1つが `object-fit: cover` による**表紙の切り抜き**だった。

> 画像利用の基本ルール：提供している商品のパッケージ画像は**拡大・縮小のみ**可能。
> その他の加工（切り抜き等）はご遠慮ください。

**`object-fit: contain` で、縮めるだけにする。** 枠に合わせて切らない。

### 6. 運営が口コミや票を書かない

darekore.jp では、サイトを活性化させたくて運営自身が口コミを書き、投票していた。
景品表示法第5条第3号（ステマ規制）に当たる。**このサイトには投稿機能を置かない。**
動いていることは、**発売予定という実データの更新**で示す。

### 7. 公開したURLは落とさない

出典から消えたらページごと消す作りにしていて、404 が119件出た。
**このサイトは月別ページを消さない。** 過去の月も残す。

## 何を出すか

| ページ | 枚数のめやす | 中身 |
|---|---|---|
| トップ | 1 | これから出るものを日付順に |
| 月別 | 12〜18 | その月に出る作品。過去の月も残す |
| ジャンル別 | 30〜60 | 作品数が一定以上のジャンルだけ |
| レーベル別 | 30〜60 | 同上 |
| このサイトについて / プライバシー | 2 | 出典・広告表記・削除依頼の窓口 |

**合わせて100〜150ページ。** darekore.jp の 0.25% の枚数で作る。

## データ取得

出典: DMM.com アフィリエイト Web サービス（FANZA / digital videoa）
<https://affiliate.dmm.com/api/>

| 環境変数 | 用途 |
|---|---|
| `FANZA_API_ID` | API ID。**必須** |
| `FANZA_AFFILIATE_ID` | アフィリエイトID。**承認が下りるまで空のままにする** |

**キーはリポジトリに書かない。** GitHub Secrets に入れる。

## 掲載データの方針

darekore.jp と同じ。

- **権利者が API で公開している項目だけを載せる。** 推測・補完・独自の評価は載せない
- 実在の人物なので、裏付けのない身体的特徴・所属・経歴を書かない
- ページには必ず出典を明示する
- 18歳未満に向けたものでない旨を出す
- 削除依頼の窓口を画面に出す
- アフィリエイトリンクには「広告」と表示する（景品表示法第5条第3号）
